# 🍓 สกุชชี่ Boutique (Squishy Shop Online)

เว็บไซต์อีคอมเมิร์ซร้านค้าออนไลน์จำหน่ายสกุชชี่พรีเมียมนำเข้าจากแบรนด์ดังระดับโลก เช่น **iBloom**, **Puni Maru** และ **Creamiicandy** ออกแบบด้วยดีไซน์น่ารัก ใช้งานง่าย ตอบสนองทุกการใช้งาน (Responsive) และมีระบบการทำงานเสมือนจริงครบถ้วน

---

## 🌟 คุณสมบัติเด่นของระบบ (Key Features)

### 1. 🏡 หน้าแรก (Home Page - `index.html`)
- แบนเนอร์สโลแกนและต้อนรับร้านสกุชชี่พรีเมียม
- การ์ดแนะนำ 3 แบรนด์หลัก (**iBloom**, **Puni Maru**, **Creamiicandy**) พร้อมลิงก์เข้าสู่หน้าแบรนด์เฉพาะ
- แสดงรายการสินค้าใหม่ล่าสุด (New Arrivals)
- ฟอร์มสมัครรับข่าวสารคอลเลกชันใหม่ (Newsletter Subscription)

### 2. 🛍️ หน้ารวมสินค้า & ระบบกรอง Real-Time (`products.html`)
- **กรองตามแบรนด์ (Brand Filter):** สามารถเลือกติ๊กแบรนด์ที่ต้องการ หรือเลือกดูทั้งหมด
- **กรองตามช่วงราคา (Price Range Slider):** ปรับสไลเดอร์เลือกราคาสูงสุดแบบ Real-Time (฿200 - ฿1,500)
- **กรองตามหมวดหมู่ (Category Filter):** แท็กหมวดหมู่ Slow Rising, Scented, Limited Edition, Jumbo Size
- **ค้นหาสินค้า (Real-Time Search):** ช่องพิมพ์ค้นหาสินค้าด้วยชื่อคีย์เวิร์ด
- **เรียงลำดับสินค้า (Sorting):** เรียงตามยอดนิยม, ราคาจากต่ำไปสูง, ราคาจากสูงไปต่ำ

### 3. 🏷️ หน้าแบรนด์สินค้าเฉพาะ (Brand Pages)
- **`ibloom.html`:** รวบรวมสินค้าทั้งหมดของแบรนด์ iBloom (เน้นความนุ่ม สโลว์ และกลิ่นหอม)
- **`punimaru.html`:** รวบรวมสินค้าทั้งหมดของแบรนด์ Puni Maru (เน้นงานปั้นสมจริง ขนมปัง ครัวซองต์)
- **`creamiicandy.html`:** รวบรวมสินค้าทั้งหมดของแบรนด์ Creamiicandy (เน้นความคาวาอี้ ตัวละคร Yummiibear/Marshmelli)

### 4. 🔍 หน้ารายละเอียดสินค้า (`product-details.html`)
- แสดงรูปภาพหลักพร้อมแกลเลอรีรูปย่อย (Thumbnail Gallery) คลิกสลับรูปได้
- เลือกขนาดสินค้า (**Jumbo** / **Mini**)
- ปุ่มเพิ่ม-ลดจำนวนสินค้า (Quantity +/-)
- ปุ่ม **"เพิ่มลงรถเข็น"** (Add to Cart) พร้อมการ์ดแจ้งเตือนแบบ Toast Notification
- ปุ่ม **"ซื้อทันที"** (Buy Now) นำเข้าสู่หน้าชำระเงินทันที

### 5. 🛒 ระบบตะกร้าสินค้า (`cart.html` & `cart-system.js`)
- จัดเก็บข้อมูลสินค้าในตะกร้าด้วย `localStorage` เชื่อมโยงข้อมูลได้ทุกหน้า
- แสดงป้ายตัวเลข (Badge) จำนวนสินค้าในตะกร้าบนแถบนำทาง (Navbar) อัปเดต Real-Time
- ปรับเพิ่ม/ลดจำนวนสินค้า หรือกดลบรายการสินค้าออกจากตะกร้า
- คำนวณราคาสินค้ารวม ค่าจัดส่ง ส่วนลดโปรโมชัน และยอดรวมสุทธิอัตโนมัติ
- รองรับการกรอกโค้ดส่วนลด (เช่น `DIS100`)

### 6. 💳 ระบบชำระเงิน & ฟอร์มกรอกข้อมูลผู้ซื้อ (Checkout Modal)
- ป๊อปอัพฟอร์มกรอกชื่อ-นามสกุล, เบอร์โทรศัพท์ และที่อยู่จัดส่ง
- เลือกช่องทางชำระเงิน (PromptPay QR Code, บัตรเครดิต/เดบิต, เก็บเงินปลายทาง COD)

### 7. 🧾 ระบบออกใบเสร็จรับเงิน / ใบกำกับภาษี (`receipt.html`)
- สร้างใบเสร็จรับเงินอัตโนมัติเมื่อชำระเงินเสร็จสิ้น
- แสดงเลขที่ออเดอร์ (`#SQ-XXXXXX`), วันที่-เวลา, ข้อมูลผู้ซื้อ, ที่อยู่จัดส่ง
- ตารางสรุปรายการสินค้าที่สั่งซื้อ ยอดรวม ชำระเงินสำเร็จ
- ปุ่ม **"พิมพ์ใบเสร็จ (Print Receipt)"** รองรับการพิมพ์ออกกระดาษหรือบันทึกเป็นไฟล์ PDF ด้วย `window.print()`

├── punimaru.html           # หน้าแสดงสินค้าแบรนด์ Puni Maru
├── creamiicandy.html       # หน้าแสดงสินค้าแบรนด์ Creamiicandy

## 🛠️ เทคโนโลยีที่ใช้ (Technologies Used)

- **HTML5:** โครงสร้างเว็บตามมาตรฐาน Semantic HTML
- **CSS3 / Tailwind CSS (v3 via CDN):** จัดการสไตล์ ตกแต่ง UI/UX โทนสีพาสเทลพีช-น้ำตาล และรองรับการแสดงผลบนสมาร์ทโฟน
- **JavaScript (ES6+):** ควบคุมการทำงานเชิงโต้ตอบ (DOM Manipulation, Event Listeners, Dynamic Filtering, Sorting)
- **Web Storage API:**
  - `localStorage`: บันทึกข้อมูลสินค้าในตะกร้าข้ามหน้าเว็บ
  - `sessionStorage`: จัดเก็บข้อมูลคำสั่งซื้อเพื่อสร้างใบเสร็จรับเงิน
- **Google Fonts:** ฟอนต์ภาษาไทย **Prompt** (Weights: 300, 400, 500, 600, 700)
